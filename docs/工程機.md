# 工程機（Engineering Sample）

**工程機**指的是還沒進入量產、只在開發與驗證階段流通的機器。它們不對外販售，但因為各種原因偶爾會流出到二手市場。

## 幾個常混用的名詞

| 名詞 | 階段 | 說明 |
|---|---|---|
| **EVT**（Engineering Validation Test） | 最早 | 驗證設計是否可行。板子可能是裸板、外殼是 3D 列印的、功能大量缺漏 |
| **DVT**（Design Validation Test） | 中期 | 設計基本定案，驗證各項規格與可靠度。外觀接近成品但仍會改 |
| **PVT**（Production Validation Test） | 後期 | 用真正的量產產線與治具小批量試產，驗證製程 |
| **MP**（Mass Production） | 量產 | 出貨版本 |
| **ES**（Engineering Sample） | — | 泛指晶片或整機的工程樣品，常特指 SoC 廠給客戶的試用晶片 |

一般講「工程機」多半是指 EVT / DVT 階段的機器。

## 工程機和量產機的差別

- **bootloader 通常是解鎖的**，或本來就跑 `userdebug` / `eng` build。這是它們對開發者有吸引力的主因——可以自由刷機、拿到 root、接 UART 看 log。
- **有額外的除錯介面**：測試點（test point）、JTAG、UART 腳位常常沒被移除。
- **軟體不完整**：相機調校、電源管理、基頻認證都可能還沒做完，日常使用會很不穩。
- **無法保固、無法 OTA**：不在正常的更新通道裡。
- **可能有 SoC 廠的內部功能沒關掉**，這也是它們在資安研究上有價值的原因——研究者可以在工程機上觀察到量產機被鎖起來的行為。

## 為什麼會流出

工程機理論上要回收銷毀，但實際上經過供應鏈多方（SoC 廠 → ODM → 品牌廠 → 測試單位）流轉，總會有漏網之魚流到二手市場。買到的風險是：功能殘缺、無法保固、以及在某些地區可能有法律爭議（設備未取得無線電認證）。

## 對開發者的意義

工程機在幾個場景很有價值：

- **韌體/kernel 開發**：解鎖的 bootloader + 外露的 UART，除錯效率遠高於零售機。
- **資安研究**：量產機關掉的除錯功能還在，可以觀察到正常情況看不到的行為。相關研究方法見 [ABL / AVB 逆向](./abl-avb-reversing.md)。
- **理解 boot flow**：能實際中斷開機流程逐階段觀察，見 [Bootloader](./bootloader.md)。

不過對一般用途來說，用零售機解鎖 bootloader（見 [Pixel Root](./pixel_root.md)）通常就足夠，且穩定得多。
