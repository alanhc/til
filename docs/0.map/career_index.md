# 職涯 / 生活 / 學習 文章索引

這一類的重心是**組織如何運作、以及你在裡面怎麼活**：為什麼大公司永遠在找 owner、
為什麼可靠的人會被過載、面試為什麼長成現在這樣，以及學習方法與生活上的自我照顧。

體例上和技術分類不同：**少數幾篇是完整成文的長文，其餘多半是素材收集**
（影片、podcast、引文的筆記）。下表會標明哪些是哪一種，省得你點進去落差太大。

---

## 一、組織、問責與結構（長文）

這三篇共用同一套理論底座，可以獨立閱讀，但連著讀最有收穫。

| 文章 | 內容 |
|---|---|
| [為什麼大公司永遠在找 Owner？](../why-big-companies-hunt-for-owners.md) | 從「這個誰 own？」這句所有工程師都聽過的話開始，五層往下拆：找 owner 是理性的（**眾手問題**）→ 業界解法是「一個名字，不能再多」→ 解法的極限（有些系統天生眾手，而 owner 會換人）→ **夾在中間的邊界角色**的結構性困境 → 陰暗面：當找 owner 變成**問責黑洞**。最後談 AI agent 如何讓這件事重新洗牌。[英文版](../why-big-companies-hunt-for-owners-en.md) |
| [當組織把你設計成備援](../redundancy-overload.md) | 上一篇的反面：基礎設施的 **N+1 redundancy** 是常識，但把同一套邏輯套在人身上會產生隱形帳單。四堵牆——冗餘設計如何拆解「你的工作」、**每件事都有兩個 owner 就等於沒有 owner**、過載如何消滅「進展感」、以及**分工不均為什麼精準砸在可靠的人頭上** |
| [為什麼公司推不動 Agentic AI](../ai-why-companies-struggle-agentic-ai.md) | 三部曲的第三篇（主要列在 [AI 系列索引](ai_index.md)）：組織對 agentic AI 的抗拒，同樣回到問責與邊界的結構問題。[英文版](../ai-why-companies-struggle-agentic-ai-en.md) |
| [當責](../當責.md) | 素材：root cause analysis 與 postmortem（事後查驗）的重點筆記 |

## 建議閱讀順序

**如果你正被組織的結構困住：**

```
為什麼大公司永遠在找 Owner？   ← 先理解「找 owner」的合理性與極限
   → 當組織把你設計成備援        ← 反面：冗餘與過載的帳單
   → 為什麼公司推不動 Agentic AI  ← 同一套結構在新技術上的重演
```

**如果你在準備面試或想清楚職涯：**

```
刷題面試：一場決策外包的共謀    ← 先看清這場遊戲的機制
   → 職涯（T 型人才、向上管理）   ← 再決定自己要長成什麼形狀
```

**如果你要快速進入一個新領域：**

```
學習（roadmap → pattern → 放射狀）
   → 英文學習（可理解輸入 + 輸出）
   → 個人成長資源
```
